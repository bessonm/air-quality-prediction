# Décisions importantes

Les Decision Records conservent le contexte, les alternatives et les conséquences
des choix structurants : périmètre, sélection des données, protocole ou modèle
retenu. Les essais intermédiaires restent dans le [journal des expériences](../experiments.md).

Créer un fichier `NNNN-short-title.md` dans ce dossier à partir du
[template MADR simplifié](../templates/decision-record.md), puis ajouter un lien
dans le registre et dans la navigation de `zensical.toml`.
Rédiger en français et garder les noms de fichiers en anglais.

Statuts possibles : proposée, acceptée, rejetée, remplacée. Lorsqu'un choix
change, conserver son historique et relier la décision qui le remplace.
